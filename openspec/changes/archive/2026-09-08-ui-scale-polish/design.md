# Design: UI Scale & Polish

## Title Parsing

Release names follow a predictable pattern generated by FunkArr's search pipeline:

```
{Series}.{SxxExx}.{EpisodeTitle}.{SxxExx}.{GERMAN}.{Quality}.{WEB}.{codec}-FunkArr
```

Examples:
```
Lass.dich.ueberwachen.S2025E01.Ein.unvergesslicher.Abend.-.fuers.Showpublikum.S2025E01.GERMAN.1080p.WEB.h264-FunkArr
Babylon.Berlin.S01E02.Folge.2.-.Staffel.1.|.Babylon.Berlin.S01E02.GERMAN.1080p.WEB.h264-FunkArr
30.Tage.Lust.S01E02.Folge.2.Liebe.S01E02.GERMAN.1080p.WEB.h264-FunkArr
```

### Parse Strategy

Create a `parseReleaseName(title: string)` utility that extracts:

```typescript
interface ParsedTitle {
  series: string        // "Lass dich überwachen"
  season: number | null // 2025
  episode: number | null // 1
  episodeTitle: string | null // "Ein unvergesslicher Abend"
  quality: string | null // "1080p"
  raw: string           // original release name
}
```

Parsing approach:
1. Find first `SxxExx` pattern — everything before it is the series name (dots to spaces)
2. Everything between first `SxxExx` and second `SxxExx` (or `GERMAN`) is the episode title
3. Extract quality from `1080p`, `720p`, `480p`
4. Strip `-FunkArr` suffix, `GERMAN`, `WEB`, codec

### Display Component

A `<ReleaseTitle>` component that renders the parsed title:

```
┌─────────────────────────────────────────────────────┐
│ Lass dich überwachen                                │
│ S2025 E01 · Ein unvergesslicher Abend   1080p       │
└─────────────────────────────────────────────────────┘
```

- Series name: `text-text-primary font-medium`
- Season/Episode: `text-brand-400 font-mono text-xs`
- Episode title: `text-text-secondary text-xs`
- Quality: badge pill `bg-surface-elevated text-xs`
- Tooltip on hover: full raw release name

Used in: QueueCard, ActiveDownloads, History table title column.

## Queue Grouping

### Data Flow

```
SSE Stream (all items)
       │
       ▼
useQueueStream() ──── items: QueueItem[]
       │
       ▼
groupBySeriesName() ──── groups: Map<string, QueueItem[]>
       │
       ▼
<QueueGroupCard>     ──── collapsible per-series section
  └── <QueueCard>    ──── individual item (existing component)
```

### Grouping Logic

Group by the parsed series name from `parseReleaseName()`. Each group shows:

```
┌─────────────────────────────────────────────────────┐
│ ▼ Babylon Berlin                    24 queued   ▸▸  │
├─────────────────────────────────────────────────────┤
│   S01E02 · Folge 2 - Staffel 1         751 MB   ○  │
│   S01E04 · Folge 4 - Staffel 1         702 MB   ○  │
│   S01E06 · Folge 6 - Staffel 1         693 MB   ○  │
│   ... +21 more                                      │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ▼ Lass dich überwachen        3 downloading  1 q.   │
├─────────────────────────────────────────────────────┤
│   S2024E02 · Die Überraschungs... ▓▓▓▓▓▓▓▓░░ 85%   │
│   S2025E01 · Ein unvergessli... ▓▓▓▓▓▓▓▓▓░ 89%     │
│   S2025E02 · Deutschlands sch.. ▓▓▓▓▓▓▓░░░ 79%     │
│   S2026E01 · Hier wird das...              Queued   │
└─────────────────────────────────────────────────────┘
```

- Groups with active downloads: expanded by default, sorted first
- Groups with only queued items: collapsed by default, show "+N more" when collapsed
- Expand/collapse toggle on group header
- Group header shows: series name, download/queued counts

### Collapse Behavior

- Groups with active downloads: always show active items, queued items collapsible
- All-queued groups: collapsed, click to expand, show first 3 + "+N more"
- "Expand All" / "Collapse All" toggle in page header

## Small Fixes

### RuleSets: Sort Alphabetically
Sort `filteredRulesets` by `topic` (case-insensitive). Add count: "61 rulesets" below search.

### History: Dynamic Categories
Fetch available categories from history data instead of hardcoding. The API already returns `category` per item — extract unique values.

### Scoring Detail: Match Filter
Add toggle buttons "All / Matched / Unmatched" above the candidate list. Filter `itemTraces` by `matched` boolean.
